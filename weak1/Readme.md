# Personal Portfolio Website Assignment

This project is a personal portfolio website created as part of the HTML5 Practical Assignment.

## Features & Concepts Covered
- **HTML5 Structure & Semantic Tags**: Used `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>`.
- **Headings & Paragraphs**: Proper text hierarchy using `<h1>` to `<h3>` tags.
- **Links & Navigation**: Smooth internal section navigation and external hyperlinks.
- **Images**: Profile images integrated with appropriate `alt` descriptions.
- **Lists**: Used unordered lists (`<ul>`) for technical skills and ordered lists (`<ol>`) for soft skills.
- **Tables**: Styled educational records in tabular format using `<table>`, `<tr>`, `<th>`, and `<td>`.
- **Forms & Buttons**: Interactive contact form containing inputs, textareas, and submit/reset buttons.
