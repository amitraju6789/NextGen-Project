# Responsive Startup Landing Page — InnovateX (Week 2 Task)

This project is built for the **Veda Technologies Internship / Training Program** as part of the **Week 2 — CSS & Responsive Design Track**.

## 🚀 Features & Learning Outcomes
- **CSS Selectors & Typography:** Clean, modern typography using sans-serif fonts, color hierarchy, and semantic structuring.
- **Box Model:** Comprehensive management of margins, paddings, borders, and global `box-sizing: border-box`.
- **Flexbox Layout:** Utilized for header navbar, hero section, button alignments, and contact form layout.
- **CSS Grid:** Implemented responsive multi-column layouts (`repeat(auto-fit, minmax(...))`) for Services, Why Choose Us, Client Feedback, and Transparent Pricing cards.
- **Positioning:** Applied `sticky` positioning for persistent header navigation across all scrolling views.
- **Media Queries:** Designed responsive breakpoints for Desktop, Tablet, and Mobile displays (`@media (max-width: 768px)`).

## 🛠️ Tech Stack
- HTML5 Semantic Structure
- CSS3 (Flexbox, CSS Grid, Media Queries, CSS Variables)

## 📌 How to View
1. Open `index.html` directly in any web browser.
2. Resize the window or use Developer Tools (`Ctrl + Shift + I` / `F12`) to inspect responsiveness across mobile, tablet, and desktop viewports.
