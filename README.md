# Responsive Business/Startup Landing Page (Week 2 Task)

This project is built for the **Veda Technologies Internship / Training Program** as part of the **Week 2 — CSS & Responsive Design Track**.

## 🚀 Features & Learning Outcomes
- **CSS Selectors & Typography:** Applied clean fonts, color schemes, and structural layout tags.
- **Box Model:** Properly configured padding, margins, borders, and `box-sizing: border-box`.
- **Flexbox Layout:** Utilized for header navigation, hero content, button alignments, and contact form design.
- **CSS Grid:** Implemented responsive multi-column layouts for Services, Features, Testimonials, and Pricing cards.
- **Positioning:** Applied `sticky` positioning for persistent header navigation.
- **Media Queries:** Designed responsive breakpoints to support Mobile, Tablet, and Desktop screen widths.

## 🛠️ Tech Stack
- HTML5
- CSS3 (Flexbox, Grid, Media Queries)

## 📌 How to View
1. Clone or download the repository.
2. Open `index.html` directly in any web browser.
3. Resize the window or inspect element mode (`Ctrl + Shift + I`) to test responsive behavior across devices.
