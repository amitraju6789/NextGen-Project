# Week 01 — Personal Portfolio Website

A responsive, semantic personal portfolio website showcasing foundational HTML5 mastery, semantic structuring, accessible design, tabular academic records, and interactive contact forms.

---

## 🚀 Live Demo
- **Live Deployed Portfolio:** [https://amit-kumar-singh-portfolio-final.vercel.app](https://amit-kumar-singh-portfolio-final.vercel.app)

---

## 🌟 Key Features & Concepts Covered
- **Semantic HTML5 Architecture:** Built using proper semantic landmarks (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **Typography & Content Hierarchy:** Logical text structure using `<h1>` through `<h3>` tags.
- **Accessible Navigation:** Smooth internal in-page section scrolling (`#home`, `#about`, `#education`, `#skills`, `#projects`, `#contact`) alongside external profile hyperlinks.
- **Tabular Data Representation:** Clean academic qualifications display using `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, and `<td>`.
- **Lists Implementation:** Unordered lists (`<ul>`) for technical skills and ordered lists (`<ol>`) for soft skills.
- **Form Handling:** Interactive contact form containing inputs, textareas, field validations, and submit/reset buttons.
