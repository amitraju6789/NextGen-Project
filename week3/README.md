# To-Do Management Application (Week 3 Task)

Built for **Veda Technologies Internship Program** under **Week 3 — JavaScript Fundamentals Track**.

## 🚀 Features
- **Add Task:** Dynamically add new items to the list.
- **Edit Task:** Modify existing task strings via dynamic prompts.
- **Delete Task:** Remove items from the list array.
- **Mark Complete:** Toggle completion state with styled visual feedback.
- **Search & Filter:** Real-time search filtering alongside All/Pending/Completed tabs.

## 🛠️ Concepts Applied
- ES6 Arrow functions & Array Methods (`map`, `filter`, `find`)
- DOM Elements Manipulation & Event Handling
- Dynamic UI Rendering
