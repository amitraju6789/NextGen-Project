# Expense Tracker Application (Week 4 Task)

Built for **Veda Technologies Internship Program** under **Week 4 — Advanced JavaScript Track**.

## 🚀 Features & Implementation
- **Income & Expense Tracking:** Calculates total balance, total income, and expenses using `map`, `filter`, and `reduce`.
- **Destructuring & Spread Operator:** Used ES6 object destructuring and `...` operator for state updates.
- **Async & LocalStorage:** Automatic persistence in `localStorage` with simulated async promise execution.
- **Search & Category Filter:** Dynamic filtering by title string and specific category types.

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (ES6+ Advanced Concepts)
