# React Task Manager (Week 5 Task)

Built for **Veda Technologies Internship Program** under **Phase 2 — Week 5 React Fundamentals Track**.

## 🚀 Features & Learning Implementation
- **Components Structure:** Separated UI into modular components (`TaskForm`, `TaskList`, `TaskItem`).
- **State & Props:** Managed application state using React's `useState` hook and passed data/callbacks down via props.
- **Controlled Inputs & Events:** Handled form submission and dynamic input binding.
- **Lists & Keys:** Rendered lists dynamically using Array `.map()` with unique keys.
- **Conditional Styling:** Displayed priority badges and strikethrough styling based on task properties.

## 🛠️️ Tech Stack
- React.js (Vite)
- JavaScript (ES6+)
- CSS3
