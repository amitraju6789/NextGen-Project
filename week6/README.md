# React Expense Tracker (Week 6 React Hooks Task)

Built for **Veda Technologies Internship Program** under **Phase 2 — Week 6 React Hooks Track**.

## 🚀 Hooks Implemented
- **`useState`:** Managed application values (form inputs, selected category filter).
- **`useEffect`:** Handled browser Local Storage synchronization and side-effects.
- **`useRef`:** Automatically focused the description input field upon initial load and transaction submissions.
- **Custom Hook (`useLocalStorage`):** Built a custom reusable state management hook for persistent browser storage.

## 🛠 Tech Stack
- React.js (Vite)
- Custom React Hooks
- CSS3
