# React Blog Application (Week 7 React Router Task)

Built for **Veda Technologies Internship Program** under **Phase 2 — Week 7 React Router & Multi-Page Applications Track**.

## 🚀 Features & Concepts Implemented
- **React Router v6 Integration:** Integrated `BrowserRouter`, `Routes`, and `Route` components.
- **Dynamic Routing:** Handled dynamic param routes (`/blog/:id`) using the `useParams` hook.
- **Client-Side Navigation:** Utilized `NavLink` for active state styling and smooth SPA transitions.
- **404 Handling:** Configured fallback wildcard route (`*`) to display a custom Not Found page.

## 🛠 Tech Stack
- React.js (Vite)
- React Router DOM v6
- CSS3
