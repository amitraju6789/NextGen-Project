# Week 11: Authentication & Form Validation System

An interactive user authentication system built with **React 19**, **Vite**, and **Tailwind CSS**.

## 🚀 Key Features
- **Live Form Validation:** Real-time feedback on input fields (Email regex check, Name length, Password complexity).
- **Password Strength Meter:** Dynamic visual meter displaying strength (Weak, Medium, Strong) based on character set analysis (uppercase, numbers, special characters).
- **Tab Switching:** Seamless toggling between **Sign In** and **Sign Up** forms.
- **Show / Hide Password:** Accessible password visibility toggles.
- **Security Checklists:** Real-time visual feedback checklist for password requirements.

## 🛠️ Tech Stack
- **Framework:** React 19
- **Build Tool:** Vite
- **Icons:** Lucide React
- **Styling:** Tailwind CSS

## 💻 Getting Started
```bash
npm install
npm run dev
```
To create a production build:
```bash
npm run build
```
